Building AI-powered creative tools for 3+ years. I work at the intersection of **browser-based media editors**, **video pipelines**, and **AI agent orchestration** — from canvas rendering with Fabric.js to multi-agent systems with LangChain and MCP servers.

---

### What I build

- **Multi-agent AI pipelines** — supervisor + specialist ReAct agents, judge agents for hallucination detection
- **Browser-based media editors** — PSD layer editors, canvas tools, drag-and-drop builders with Fabric.js
- **Video infrastructure** — adaptive HLS streaming, multi-bitrate encoding with FFmpeg
- **SEO & content automation** — blog pipelines with AI-generated content and images
- **MCP servers** — custom tool servers for the Model Context Protocol ecosystem
